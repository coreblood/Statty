# Statty

Stat Feed + stat conversion planner for the Uncapped 3.3.5a server, in one addon.

Statty shows your live per-kill stat gains and lets you plan how the server
auto-converts them — green stats receive a percentage share, red stats are
dumped and converted as you earn them, banked stats are untouched.

**Install:** download `Statty.zip` from the latest
[release](https://github.com/coreblood/Statty/releases), unzip into
`World of Warcraft\\Interface\\AddOns\\`, and fully restart the client.

Open with the minimap button or `/statty`. See the **Statty Guide** PDF (on the
release) for full usage, or **Statty in a nutshell** for the quick version.
